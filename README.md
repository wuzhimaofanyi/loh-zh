- 解压后双击 Lordling of Hearts.exe 开始游戏
- 遇到闪退/黑屏/文字乱码：用包里的「双击我-记录报错并启动.bat」复现一次，把生成的 错误日志.txt 反馈
- 更新方式：新版会以同样的文件名发布在新 Release 里，上面的 latest 链接自动指向最新版，不需要换链接
